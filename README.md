# Code Formatter

Format, minify and validate 46 languages in your browser.

**Live:** https://codeformatter.useful-indeed.com

Code Formatter is a single-page beautifier and validator for 46 languages — JSON, YAML, XML, HTML, CSS, JavaScript, TypeScript, Python, Go, Java, C/C++, C#, PHP, Dart, Lua, Shell, many SQL dialects and more. Paste code, pick a language (or let it auto-detect), and get clean, consistently indented output. Errors show the exact line and column.

## How to use

1. Paste your code, drop a file, or open one from your device.
2. Pick a language from the list, or leave it on Auto-detect.
3. Choose 2 spaces, 4 spaces or tabs, then click Format (or Minify for JSON, XML and CSS).
4. Copy the output, or use it as the new input. The Logs panel shows what happened.

## Privacy

Everything runs in your browser. Your browser's local storage remembers your last language, your theme and whether you liked the tool. Your code is not stored.
