How it works ↓

Free online code formatter

Code Formatter cleans up messy code in one click. Paste JSON, SQL, HTML, CSS, JavaScript, Python, Go or any of 46 languages and dialects, and get neatly indented, readable code back. It can also minify code and check it for errors, showing the exact line and column of each problem. Your code is formatted inside your browser, not on a server.

How to use it

  1. Paste your code into the Input box, or click Open file. Click Sample to try it with example code.
  2. Pick the language, or leave it on Auto-detect and it will guess for you.
  3. Choose Format to make it readable, or Minify to make it as small as possible. Pick 2 spaces, 4 spaces or tabs.
  4. Copy the result, or click ← Use as input to keep working on it. Any problems are listed in Logs with their line and column.

Why format your code?

Well-formatted code is easier to read, review and debug. A single long line of JSON from an API is nearly impossible to scan, but formatted it shows every field at a glance. Formatting SQL makes joins and conditions easy to follow, and consistent indentation keeps code reviews focused on what the code does, not how it's spaced. Minifying does the opposite: it makes files smaller for production.

Questions

Is my code uploaded anywhere?

No. Formatting happens in your browser. The page downloads the formatting engines (for example Prettier) from a public code library the first time you use a language, but your code itself is never sent.

Why does it say my JSON is invalid?

Common causes are a missing comma, a trailing comma after the last item, single quotes instead of double quotes, or comments. The Logs panel shows the line and column. Turn on Auto-fix errors to repair the most common ones automatically.

What's the difference between Format and Minify?

Format adds indentation and line breaks so people can read the code. Minify removes them so the file is as small as possible, which is useful for production websites and APIs.

Can I format very large files?

Yes, within what your device's memory allows. Files of a few megabytes are usually fine on a laptop.

Does it work on my phone?

Yes. On small screens the input, output and logs stack on top of each other.
